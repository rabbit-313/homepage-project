# ru-portfolio: 文言改善とモバイル表示の調整

## 背景・目的

ru-portfolio サイトの公開文言のうち、Services（提供サービス）の特徴リストと Skills のタグが「・」区切りで一続きのテキストとして表示されており、箇条書きではなく文章の羅列のように見える。また Services の3カードの説明文がすべて同一パターンの文末表現になっており単調に見える。加えて、モバイル幅で確認したところ、各セクションに `min-height: 100vh` が適用されているため、文字量が少ないセクションで上下に大きな空白ができ、スクロール体験が間延びして見える。

これらを解消し、サイトの既存デザイン言語（オークウッド調の配色、Fraunces書体によるエディトリアルなタイポグラフィ、細い罫線とドット区切り）を維持したまま、読みやすく魅力的な表示に調整する。

## スコープ

### 対象

1. `.service-features`（Services セクションの特徴リスト）の表示形式変更
2. Services セクションの本文（3カード）の文末表現の調整
3. モバイル幅（`max-width: 768px`）における `.section` の `min-height: 100vh` の解消

### 対象外

- Skills のタグ（`.skill-tags`）表示形式 — 短い単語の羅列で可読性に問題がないため現状維持
- セクションの並び順・構成
- Hero の文言
- About の経歴・自己紹介文、Publications の論文情報などの事実情報
- three.js のパーティクル演出
- 配色・フォント・全体レイアウト構造

## 変更方針

### 1. 表示形式の変更

現在 `.service-features li` は `display: inline` で、項目間に `::before { content: '·' }` を挿入する実装になっている。これにより4項目が改行なしの一続きの文章のように表示される。

変更後は各項目を独立した行に並べる縦型リストにする。項目間の「・」区切りではなく、各行の先頭にエンダッシュ（–）を目印として置く形にし、色は既存のドット区切りと同じ `--oak-warm` を使用する。これにより既存のドット区切りの意匠を保ったまま視認性を上げる。

バッジ／ピル型（背景色付きの丸みを帯びたタグ）にする案も検討したが、サイト全体の細い罫線・ドット区切りによる控えめなエディトリアルなデザインと質感が合わなくなるため採用しない。

### 2. 文言の調整

Services の3カードの本文がすべて「〜を行います」「〜を支援します」で終わる同一パターンになっているため、内容（何をするか）は変えずに文末表現のみ調整し、テンプレート感を消す。

| カード | Before | After |
|---|---|---|
| MLモデル開発 | 推薦システム、画像認識、自然言語処理など、ビジネス課題に最適な機械学習モデルの設計・開発・評価を行います。 | 推薦システム、画像認識、自然言語処理など、ビジネス課題に応じて機械学習モデルを設計・開発・評価します。 |
| MLインフラ構築 | MLモデルを本番環境で安定して運用するためのパイプライン設計、インフラ構築、MLOpsの導入を支援します。 | MLパイプラインの設計からクラウドインフラ構築、MLOps導入まで、本番環境で安定運用できる仕組みをつくります。 |
| 技術コンサルティング | ML/AIの導入検討から技術選定、チーム立ち上げまで、技術的な意思決定をサポートします。 | ML/AI導入の技術検証から技術選定、チーム立ち上げまで、意思決定に必要な判断材料を整理します。 |

各カードの特徴リスト（`<li>` の中身）はテキスト自体を変更せず、表示形式のみ変更する。

About / Skills / Publications / Contact は元々プロースまたはシンプルな情報表示で「羅列」の問題がないため、文言変更は行わない。

### 3. モバイルの余白修正

`@media (max-width: 768px)` 内の `.section` ルールに `min-height: auto;` を追加し、`min-height: 100vh` の強制指定を解除する。上下の余白は既存の `padding` のみで確保する。

スクロールスナップ（`scroll-snap-type: y proximity`）は既に緩やかな挙動のため変更しない。

## 動作確認

- ローカルサーバーでモバイル幅（375px）・デスクトップ幅の両方をブラウザで目視確認する
- Services の特徴リストが縦並びで表示され、一続きの文章に見えないことを確認する
- 各セクション間の余白が間延びしていないことを確認する
- 経歴・スキル・論文などの事実情報が変更されていないことを確認する
